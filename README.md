
KMAgent v2.0 简单好用的本地知识库智能体，纯 CPU 就能跑的本地知识库智能体(显卡贵不存在)，数据不出本地无云端消费(Token贵不存在)。

KMAgent 核心优势：
开箱即用：极简部署，无需专业团队和运维投入。
零显卡成本：纯 CPU 推理，一台普通电脑即可运行。
数据零外传：全量数据本地落盘，隐私与资产自主可控。
场景全覆盖：垂直行业人机知识对齐、技能文档资产化管理、MCP 服务对外输出。

个人版和企业版的区别：
个人版企业版都有的功能：本地知识库检索LLM推理、知识库文档管理、增强版Markdown编辑器、提示词分类管理、导出WebApp、生成APK应用。
企业版特有功能：gpu加速、多模态支持、mcp服务、智能体+扩展工具、多端点服务。
